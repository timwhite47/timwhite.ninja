## How to check a source

Download the document from its URL (or the archive link, where one exists) and compare:

```sh
shasum -a 256 <downloaded-file>
```

A matching hash means you are reading the same bytes this investigation read. A mismatch means the publisher has changed the document since 2026-10-16.
