## What is in it

| Column | Type | Meaning |
|---|---|---|
| `t_s` | integer | Simulated seconds since the start of the day, in [0, 86400). |
| `agent_id` | string | Synthetic identifier, `A0001` onward. |
| `event` | string | `join`, `post`, `reply`, `read`, `probe`, or `request`. |
| `target` | string | `board`, or `hf` (attackers' `probe` and `request` only). |
| `thread_id` | string | Board thread, `T001` to `T040`. |
| `outcome` | string | `ok`, `blocked`, or `error`. |
| `marker` | string | Empty, or `m1` to `m6`: a toy per-agent signature repeated on that agent's posts. |

## How to regenerate

```sh
python generate_swarm_timeline.py --agents 1200 --attackers 700 --seed 42 --out swarm_timeline.csv
```

Standard library only; output is deterministic for a given seed and Python version.

## Known limitations

Distributions are uniform or simple mixtures. Attackers' actions against the second target are drawn from a later window than board activity, so the replay shows a phase change by construction.
