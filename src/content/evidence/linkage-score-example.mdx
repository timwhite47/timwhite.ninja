## What it measures

Two views of "these two agents look alike". The modus-operandi view compares ordered event-type trigrams. The signature view compares rare markers that serve no task purpose.

## Run it

```sh
python linkage_score.py swarm_timeline.csv --top 10 --min-events 5
```

## Reading the output

Each view prints its top pairs with a Jaccard score. The final section lists pairs the signature view links but the modus-operandi view does not.
